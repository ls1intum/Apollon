Edit Apollon diagrams directly inside IntelliJ IDEA and WebStorm. Install the new JetBrains
plugin, then open or create a `.apollon` file to get the full canvas — draw class, object,
use-case, activity, and other UML diagrams — plus one-click SVG/PNG export and auto-export
on save.
